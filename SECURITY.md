# Security Policy

## Supported versions

Security fixes are applied to the latest release and the default branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Email
`contact@lynote.ai` with:

- the affected component and version;
- steps to reproduce;
- the likely impact; and
- any suggested mitigation.

We aim to acknowledge reports within five business days. Please avoid including
API keys, private user content, or other sensitive data in the report.

## Responsible use

Detector output is probabilistic and must not be treated as proof of authorship
or provenance. Do not use these tools as the sole basis for disciplinary, legal,
employment, or moderation decisions.
